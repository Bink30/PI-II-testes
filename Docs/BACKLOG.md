# 🗃️ Backlog (Ideias e novas features)

Este documento contém ideias, melhorias e funcionalidades futuras que **não** estão no escopo inicial (Roadmap principal), mas que podem ser implementadas em versões futuras para evoluir a plataforma.

## 🛍️ Experiência do Cliente (UX/UI)
- [ ] **Histórico de Pedidos:** Criar uma área logada onde o cliente pode ver os pedidos anteriores.
- [ ] **Avaliações e Comentários:** Permitir que os clientes deixem reviews (estrelas) nos produtos.
- [ ] **Lista de Desejos (Wishlist):** Botão de "coração" para salvar produtos favoritos.
- [ ] **Recuperação de Senha Real:** Integrar o fluxo de "Esqueci minha senha" com envio de e-mail automático via Firebase.
- [ ] **Dark Mode:** Suporte a tema escuro na interface.

## ⚙️ Administrativo e Operacional
- [ ] **Controle de Estoque Avançado:** Abater o estoque automaticamente quando um pedido for finalizado via WhatsApp (requer confirmação manual do admin).
- [ ] **Gestão de Cupons de Desconto:** Criar códigos promocionais aplicáveis no carrinho.
- [ ] **Relatórios de Vendas:** Dashboard com gráficos de acessos e produtos mais clicados.

## 💳 Financeiro / Integrações
- [ ] **Gateway de Pagamento Integrado:** Substituir o checkout via WhatsApp por pagamento direto no site (Stripe, Mercado Pago ou Pagar.me).
- [ ] **Cálculo de Frete:** Integração com a API dos Correios ou Melhor Envio direto no carrinho.
